# JS OOP Classes Demos

Small vanilla JavaScript exercises covering object methods and ES class syntax with private fields.

## Features

- **Task 1** — an object with methods for balance, discount, and order management
- **Task 2** — a `Storage` class with a private items array, exposing add/remove/get operations
- **Task 3** — a `StringBuilder` class with a private value, supporting `padStart`, `padEnd`, and `padBoth`

## Technology

- Vanilla JavaScript (ES2022 classes with private fields)

## Running

Open `index.html` in a browser with the developer console open, or run each task script directly with Node:

```
node js/task-01.js
node js/task-02.js
node js/task-03.js
```
